# 채팅 진입과 경기일정 조회 정책

> 라벨: `CURRENT`  
> 상태: MVP1 기준 정책  
> 기준: 로그인 사용자 + 선택적 응원팀 설정 + KBO 야구 범위 제한

## 1. 목적

이 문서는 사용자가 채팅을 시작할 때의 진입 흐름, 응원팀 선택 정책, 야구 외 질문 차단 기준, 경기일정 조회 tool 사용 기준을 정의한다.

이 정책은 이후 LLM tool routing, 프론트엔드 온보딩 UI, 평가 데이터셋 작성의 기준으로 사용한다.

## 2. 확정 정책 요약

현재 단계에서는 다음 정책을 기본으로 한다.

1. 로그인은 채팅 시작 시 필수다.
2. 팀 선택은 선택 사항이다.
3. 팀을 선택하지 않아도 자유 질문은 가능하다.
4. 팀이 필요한 일정 질문에서 팀 정보가 없으면 되묻는다.
5. 팀 선택 유저는 `favorite_team_id`를 기본 `team_id`로 사용한다.
6. 질문에 명시된 팀은 `favorite_team_id`보다 우선한다.
7. 경기일정 조회 tool은 일정/경기 상태 의도일 때만 호출한다.
8. 야구 외 질문은 정중히 거절한다.

## 3. 채팅 진입 정책

비로그인 사용자가 채팅 입력을 시도하면 로그인 화면 또는 로그인 모달로 전환한다.

```text
비로그인 사용자
→ 채팅 입력 시도
→ 로그인 화면 또는 로그인 모달
→ 로그인 완료
→ 기존 채팅 화면으로 복귀
```

로그인 완료 후 응원팀 선택은 강제하지 않는다. 대신 사용자가 팀을 선택하면 일정, 구장, 직관 정보를 더 빠르게 맞춰줄 수 있음을 안내한다.

예:

```text
응원팀을 선택하면 경기 일정과 직관 정보를 더 빠르게 알려드릴 수 있어요.
```

## 4. 팀 선택 정책

팀 선택은 필수가 아니라 개인화를 위한 선택 입력이다.

팀 선택 UI 위치는 아직 확정하지 않는다. 후보는 다음과 같다.

- 좌측 또는 우측 사이드바
- 프로필 또는 설정 화면
- 첫 채팅 화면 안의 CTA
- 로그인 직후 온보딩 UI

엔지니어링 정책은 UI 위치와 무관하게 `favorite_team_id`가 있을 수도 있고 없을 수도 있다고 가정한다.

```text
favorite_team_id: str | None
```

## 5. 팀 미선택 사용자 정책

로그인했지만 팀을 선택하지 않은 사용자는 자유롭게 질문할 수 있다.

### 5.1 팀 없이 답변 가능한 질문

질문 자체에 팀이 있거나, 팀이 필요하지 않은 야구 질문은 바로 처리한다.

예:

```text
오늘 롯데 경기 있어?
사직구장 처음 가는데 뭐 챙겨야 해?
야구 규칙 알려줘
```

### 5.2 팀이 필요한데 없는 질문

경기일정 조회가 필요한 질문이지만 팀이 없으면 되묻는다.

예:

```text
사용자: 오늘 경기 있어?
답변: 어느 팀 기준으로 확인할까요? 예: 롯데, LG, 한화
```

### 5.3 첫 질문이 일정 관련이 아닌 경우

첫 질문이 경기일정 관련이 아니라면 경기일정을 먼저 알려주지 않는다. 사용자의 질문 의도에 답하는 것이 우선이다.

답변 끝에 팀 선택을 가볍게 유도할 수는 있다.

```text
응원팀을 선택해두면 다음에는 경기 일정과 구장 정보를 바로 맞춰드릴 수 있어요.
```

## 6. 팀 선택 사용자 정책

로그인했고 `favorite_team_id`가 있는 사용자는 해당 팀을 기본 context로 사용한다.

예:

```text
favorite_team_id = LOTTE
```

사용자 질문:

```text
오늘 경기 있어?
```

tool 입력:

```json
{
  "team_id": "LOTTE",
  "date": "Asia/Seoul 기준 오늘",
  "date_from": null,
  "date_to": null
}
```

질문에 명시된 팀이 있으면 명시된 팀이 우선한다.

예:

```text
favorite_team_id = LOTTE
사용자: LG 오늘 경기 있어?
```

tool 입력:

```json
{
  "team_id": "LG",
  "date": "Asia/Seoul 기준 오늘",
  "date_from": null,
  "date_to": null
}
```

## 7. 경기일정 조회 tool 사용 기준

`find_kbo_game`은 사용자가 경기 일정, 경기 유무, 경기 상태, 취소 사유, 점수, 날짜, 상대팀, 구장을 묻는 경우에만 호출한다.

### 7.1 호출하는 질문

예:

```text
오늘 롯데 경기 있어?
롯데 7월 일정 알려줘
7월 17일 롯데 경기 왜 취소됐어?
LG 개막전 어디서 해?
이번 주 한화 일정 보여줘
내일 잠실 경기 있어?
```

### 7.2 호출하지 않는 질문

예:

```text
야구 규칙 알려줘
사직구장 처음 가는데 뭐 챙겨야 해?
롯데 자이언츠 역사 알려줘
응원가 문화 알려줘
```

### 7.3 현재 tool만으로 처리 어려운 질문

다음 질문은 일정 DB만으로는 답변이 어렵다. 필요하면 추가 tool 또는 추가 데이터가 필요하다고 안내한다.

예:

```text
오늘 경기 우천 취소될까?
오늘 잠실 날씨 어때?
지금 티켓 남았어?
좌석 어디가 제일 잘 보여?
```

## 8. 야구 외 질문 차단 정책

이 서비스는 KBO 야구 직관 가이드에 한정한다.

답변 가능 범위:

- KBO
- 경기일정
- 경기 상태와 취소 사유
- 팀
- 구장
- 좌석
- 티켓
- 교통
- 응원
- 야구 규칙
- 직관 준비

범위 밖 질문은 정중히 거절하고 야구 관련 질문으로 유도한다.

예:

```text
사용자: 비트코인 전망 알려줘
답변: 이 서비스는 KBO 야구와 직관 정보를 돕는 서비스라 해당 주제는 답변할 수 없어요. 경기 일정, 구장, 좌석, 응원팀 관련 질문은 도와드릴 수 있습니다.
```

## 9. LLM routing 평가 기준

이 정책을 기준으로 LLM routing 평가셋을 만든다.

평가 항목:

- 야구 범위 질문인지 분류했는가
- `find_kbo_game` 호출 필요 여부를 맞췄는가
- `team_id`를 올바르게 추출했는가
- `date`, `date_from`, `date_to`를 올바르게 추출했는가
- 팀 미선택 상태에서 필요한 경우 되묻기를 선택했는가
- 질문에 명시된 팀을 `favorite_team_id`보다 우선했는가

초기 평가셋은 다음 카테고리를 포함한다.

- 명확한 일정 조회
- 취소/상태/점수 조회
- 팀명 별칭 포함 질문
- 상대 날짜 포함 질문
- tool이 불필요한 야구 질문
- 야구 외 질문
- 모호해서 되물어야 하는 질문
