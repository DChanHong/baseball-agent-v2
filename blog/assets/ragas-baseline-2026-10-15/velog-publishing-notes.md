# Velog 게시 준비

본문: `blog/blog-7-ragas-golden-dataset-baseline-draft.md`

## 이미지 배치

본문 Markdown을 붙여 넣은 뒤 로컬 상대 이미지 경로 세 곳에 아래 PNG를 Velog 편집기로 업로드하고, Velog가 발급한 이미지 구문으로 교체한다. 모든 그림은 일반 PNG이며 API 호출 없이 기록된 결과 JSON에서 생성했다.

1. `01-dataset-composition.png`: 데이터셋 구성 설명 다음.
2. `02-ragas-metrics.png`: 평가 결과 표 앞.
3. `03-required-fact-coverage.png`: 기대 사실 대조 결과 앞.

그래프를 캡처해서 다시 축소하기보다 원본 PNG를 업로드한다. 한국어 글꼴과 주의 문구를 이미지 자체에 포함했다.

## 데이터셋 제시 방식

- 본문에는 유형별 구성과 질문 / 기대답변 / 출처 / 확인할 점 형태의 대표 5건을 보여준다.
- JSON 한 건은 구조를 설명하는 축약 예시로 넣는다. 기대답변과 실제 출력이 다르다는 설명을 유지한다.
- `dataset-50-case-overview.md`는 전체 질문을 읽기 좋은 표로 정리한 부록이다. 필요하면 별도 Velog 글로 붙여 넣고 본문에서 연결한다.
- `dataset-5-examples.json`은 대표 5건의 읽기용 파일이며 실제 평가용 스키마는 아니다.
- 원본 데이터셋 전체는 기존 커밋의 GitHub 링크로 연결한다. 아직 push하지 않았으므로 **게시 전에 링크가 독자에게 열리는지 확인**한다. 비공개 저장소라면 읽기용 부록을 별도 게시하고 GitHub 링크는 그 공개 URL로 교체한다. 내부 실행 JSON을 공개해야만 글을 게시할 수 있는 것은 아니다.
- 원본 JSON의 과거 단계별 `not_run`·검수 대기 메모와 실제 실행 결과를 혼동하지 않도록, 실행 여부는 2026-10-15 결과를 기준으로 설명한다.

## 게시 직전 확인

- 본문에는 자동 평가가 높은 숫자를 보였다는 사실과, 제외 분모·judge 한계·사람 검수 전 상태를 함께 유지한다.
- Answer relevancy 0.129를 정답률로 바꾸지 않는다. 입력 형식이 원인이라고 확정하지 않는다.
- 비용은 약 $0.481의 상한 추정이며 확정 청구액이 아니다.
- 합성 경기의 18:30을 실제 KBO 일정으로 표현하지 않는다.
- 현재 실제 답변 전문을 새로 공개하지 않는다. 본문 사례의 설명은 결과 기록의 요약이다.

권장 태그: `RAG`, `RAGAS`, `AI Agent`, `LLM`, `평가`, `개발일지`

## 그림과 부록 재생성

matplotlib과 한국어 font가 있는 Python에서 저장소 루트 기준으로 실행한다.

```bash
python blog/assets/ragas-baseline-2026-10-15/generate_figures.py
```

원본 후보 데이터셋과 결과 JSON을 읽기만 한다. DB 접속·평가 재실행·유료 모델 호출은 하지 않는다. macOS에서는 Apple SD Gothic Neo를 사용하고, 다른 OS에서는 사용 가능한 한국어 font로 설정을 조정한다.
